# Aarsh's Blog

Personal blog built with [Jekyll](https://jekyllrb.com/). Thoughts on code, design, and everything in between.

## Features

- Dark/light theme with system preference detection and manual toggle
- Scroll progress bar on posts
- Syntax highlighting via Rouge
- RSS feed, SEO tags, sitemap
- Responsive design

## Local Development

**Prerequisites:** Ruby, Bundler

```bash
bundle install
bundle exec jekyll serve
```

Visit `http://localhost:4000`.

## Stack

- Jekyll 4.3
- Pure CSS (no frameworks)
- Vanilla JS
